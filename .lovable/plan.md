# แผนทำให้ “คลังความรู้จาก URL” ใช้งานได้จริง

## ผลการตรวจสอบ
- ตอนนี้ URL ที่เพิ่มในหน้าสร้าง Agent ถูกบันทึกเป็นข้อความใน Agent เท่านั้น ยังไม่มีการเปิดหน้าเว็บ ดึงเนื้อหา หรือสร้างดัชนีให้ Agent ค้นหา
- ระบบประมวลผลจริงมีเฉพาะไฟล์อัปโหลด ซึ่งผ่านขั้นตอนแยกข้อความ สร้างส่วนย่อย และนำไปค้นหาตอนตอบ
- ข้อมูลจริงในระบบพบ Agent ที่เก็บ URL ไว้ 1 รายการ แต่ไม่มีรายการประมวลผล URL หรือส่วนเนื้อหาที่สร้างจาก URL จึงยืนยันได้ว่ายังไม่ได้ crawl

## สิ่งที่จะทำ
1. **สร้างรายการแหล่งความรู้แบบ URL**
   - เก็บ URL แยกเป็นรายรายการ พร้อมสถานะ `กำลังอ่าน / พร้อมใช้ / ผิดพลาด`
   - เก็บชื่อหน้าเว็บ เวลาที่อ่านล่าสุด ข้อความผิดพลาด และเนื้อหาที่สกัดได้
   - ผูกสิทธิ์กับเจ้าของ Agent เช่นเดียวกับไฟล์ความรู้

2. **อ่านเฉพาะหน้า URL ที่ผู้ใช้ระบุ**
   - เมื่อเพิ่ม URL ระบบจะดึงเฉพาะหน้านั้น ไม่ตามลิงก์ไปหน้าอื่น
   - สกัดเฉพาะเนื้อหาหลัก ลดเมนู โฆษณา และส่วนประกอบที่ไม่เกี่ยวข้อง
   - จำกัดเวลาและขนาดข้อมูล พร้อมตรวจ URL และป้องกันการเข้าถึงเครือข่ายภายใน
   - นำข้อความเข้าสู่ขั้นตอนแบ่งเนื้อหาและสร้างดัชนีเดียวกับไฟล์อัปโหลด

3. **ปรับหน้าสร้างและหน้ารายละเอียด Agent**
   - ตรวจรูปแบบ URL, กันรายการซ้ำ และแสดงข้อผิดพลาดชัดเจน
   - หลังสร้าง Agent ให้เริ่มอ่าน URL จริงโดยอัตโนมัติ
   - ในแท็บ “คลังความรู้” แสดง URL พร้อมสถานะ จำนวนเนื้อหาที่อ่านได้ และเวลาอัปเดตล่าสุด
   - เพิ่มปุ่ม “อัปเดตข้อมูล” ราย URL ตามที่เลือกไว้ และปุ่มลบที่ลบข้อมูลดัชนีที่เกี่ยวข้องด้วย

4. **รองรับข้อมูล URL เดิม**
   - ย้าย URL ที่เคยเก็บอยู่ใน Agent มาเป็นรายการแหล่งความรู้ โดยไม่สร้างรายการซ้ำ
   - เก็บช่องเดิมไว้ชั่วคราวเพื่อไม่ให้ Agent เก่าเสียหาย แต่ให้ระบบใหม่ใช้รายการแหล่งความรู้เป็นหลัก

5. **ตรวจการใช้งานจริงครบวงจร**
   - ทดสอบ URL ปกติ, URL ซ้ำ, URL ผิดรูปแบบ, หน้าเข้าไม่ได้, หน้าเปลี่ยนเส้นทาง และ URL เครือข่ายภายใน
   - ยืนยันว่าเนื้อหาถูกสร้างเป็นส่วนค้นหา และ Agent ตอบจากข้อมูล URL พร้อม citation ได้
   - ทดสอบปุ่มอัปเดตเองว่าดึงเนื้อหาใหม่และแทนที่ดัชนีเดิมอย่างถูกต้อง
   - ตรวจทั้งหน้าแชท, API และ widget ให้ใช้ความรู้จาก URL ชุดเดียวกัน

## รายละเอียดทางเทคนิค
- ใช้บริการอ่านหน้าเว็บฝั่งเซิร์ฟเวอร์เพื่อรองรับหน้าเว็บสมัยใหม่ โดยไม่เปิดเผยกุญแจบริการแก่เบราว์เซอร์
- เพิ่ม metadata แหล่งที่มาใน `knowledge_files` และนำ pipeline เดิม `sanitize → chunk → embedding → retrieval` กลับมาใช้
- citation ของ URL จะเปิดไปยัง URL ต้นทาง ส่วน citation ของไฟล์ยังเปิดหน้าดูไฟล์เดิม
- เพิ่ม automated tests สำหรับ validation, SSRF protection, ingestion, re-indexing, failure status และ retrieval
