# ยกระดับหน้า Skills ให้ใช้งานง่ายและทำงานได้จริง

## สิ่งที่ตรวจพบจริงในระบบตอนนี้

- หน้า Skills เก็บ **ชื่อ** และ **คำอธิบาย** ได้ แต่เวลา Agent ตอบจริง ระบบส่งไปให้ AI **เฉพาะชื่อ skill เท่านั้น** (ตรวจแล้วในโค้ดฝั่งเซิร์ฟเวอร์ที่ประกอบคำสั่งให้ Agent) — คำอธิบายที่ผู้ใช้ตั้งใจเขียนไว้ไม่ถูกใช้เลย
- ผลคือ skill ทำงาน "แค่พอเป็นป้ายกำกับ" เช่นส่งคำว่า "ตอบลูกค้า" ไปเฉย ๆ AI จึงไม่ได้เก่งเฉพาะทางขึ้นจริงตามที่ผู้ใช้คาดหวัง
- หน้า Skills ยังเป็น **ภาษาอังกฤษล้วน** ทั้งที่ทั้งแอปใช้ไทยเป็นค่าเริ่มต้น
- หน้า Skills เป็นรายการเปล่า ๆ ไม่มีค้นหา ไม่บอกว่า skill ไหนถูก Agent ตัวไหนใช้อยู่ และลบได้โดยไม่เตือนว่ามี Agent ใช้อยู่
- ไม่มีตัวอย่าง skill สำเร็จรูปให้เริ่มต้น ผู้ใช้ต้องคิดเองตั้งแต่ศูนย์

## สิ่งที่จะทำ

### 1. ทำให้ skill "ทำงานจริง"

- เพิ่มช่อง **"คำสั่งประจำ skill"** (instructions) ในแต่ละ skill — บอกวิธีทำงาน น้ำเสียง รูปแบบคำตอบ สิ่งที่ห้ามทำ
- เวลา Agent ตอบ ระบบจะส่ง **ชื่อ + คำสั่งประจำ skill ฉบับเต็ม** เข้าไปในคำสั่งของ Agent (ทั้งในแชท, API และวิดเจ็ต) แทนการส่งแค่ชื่อ
- รองรับข้อมูลเดิม: Agent ที่เก็บไว้เป็นชื่อล้วนยังทำงานเหมือนเดิม ไม่ต้องแก้อะไร

### 2. ปรับ UX/UI หน้า Skills ให้เป็นมืออาชีพ

- แปลเป็นภาษาไทย/อังกฤษครบทั้งหน้า ตามภาษาที่เลือกในแอป
- เปลี่ยนจากรายการยาวเป็น **การ์ดแบบกริด** แสดงชื่อ, คำอธิบายย่อ, ป้ายบอกว่ามีคำสั่งประจำแล้วหรือยัง และ **จำนวน Agent ที่ใช้ skill นี้**
- เพิ่ม **ช่องค้นหา** และตัวกรอง "ใช้อยู่ / ยังไม่ถูกใช้"
- **คลังตัวอย่างสำเร็จรูป**: ปุ่ม "เพิ่มจากตัวอย่าง" ให้เลือก skill พร้อมคำสั่งจริงที่ใช้ได้ทันที เช่น ตอบลูกค้า/สรุปเอกสาร/เขียนคอนเทนต์/วิเคราะห์ข้อมูล/แปลภาษา/คัดกรองผู้สนใจ
- กล่องสร้าง/แก้ไขใหม่: มีคำอธิบายสั้นใต้ทุกช่อง, ตัวนับตัวอักษร, ปุ่มใส่ตัวอย่างคำสั่ง, เตือนชื่อซ้ำทันทีก่อนกดบันทึก
- ก่อนลบ: บอกชัดว่ามี Agent กี่ตัวใช้อยู่ และชื่ออะไรบ้าง
- สถานะกำลังโหลดแบบ skeleton และหน้าว่างที่ชวนเริ่มต้นด้วยตัวอย่าง

### 3. ตรวจสอบว่าใช้งานได้จริง

- ทดสอบวงจรเต็ม: สร้าง skill ที่มีคำสั่งชัดเจน → ผูกกับ Agent → คุยกับ Agent → ยืนยันจากบันทึกการทำงานว่า Agent ได้รับคำสั่งของ skill นั้นและตอบตามรูปแบบที่กำหนด
- เพิ่มชุดทดสอบอัตโนมัติสำหรับการอ่าน/ประกอบคำสั่ง skill ทั้งแบบเก่า (ชื่อล้วน) และแบบใหม่

## รายละเอียดทางเทคนิค

- `skills`: เพิ่มคอลัมน์ `instructions text` (migration + GRANT/RLS เดิมครอบคลุมอยู่แล้ว)
- `agents.tools._skills`: รองรับทั้ง `string[]` เดิม และ `{name, instructions}[]` แบบใหม่ โดยบันทึก snapshot คำสั่ง ณ เวลาที่เลือก เพื่อไม่ให้พฤติกรรม Agent เปลี่ยนเองเมื่อผู้ใช้แก้คลัง
- `supabase/functions/_shared/agent-settings.ts`: ปรับ `strArray` เป็น parser ที่รับสองรูปแบบ และ `applyAgentSettings` แทรกคำสั่งประจำ skill ลง system prompt
- `src/lib/agentTools.ts` + `agentTools.test.ts`: อัปเดต `getSkills`/`withPromptAndSkills` และเคสทดสอบ
- `src/hooks/useSkills.ts`: เพิ่ม `instructions`, และ query นับจำนวน Agent ที่ใช้แต่ละ skill
- `src/pages/Skills.tsx`: เขียนหน้าใหม่ตามข้อ 2, `src/components/SkillSelector.tsx`: แสดงคำอธิบาย/สถานะคำสั่ง, `src/i18n/th.ts` + `en.ts`: ข้อความใหม่ทั้งหมด
- deploy `chat` และ `agent-api` หลังแก้ shared settings
