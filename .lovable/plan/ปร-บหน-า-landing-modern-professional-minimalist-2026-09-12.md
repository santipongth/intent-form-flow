# ปรับหน้า Landing: Modern Professional Minimalist

## เป้าหมาย
ยกระดับหน้าแรกของ ThoughtMind ให้ดูเป็นผลิตภัณฑ์ AI ระดับมืออาชีพ เรียบคม แต่มีเอกลักษณ์ โดยทำให้โลโก้และชื่อแบรนด์เด่นตั้งแต่หน้าจอแรก และยังพาผู้ใช้ไปสร้าง Agent ได้ทันที

## สิ่งที่จะปรับ

### 1. แถบนำทางและแบรนด์
- ขยายโลโก้เดิมและจัดเป็น brand lockup ที่อ่าน “ThoughtMind” ชัดเจน พร้อมพื้นที่หายใจมากขึ้น
- ทำแถบนำทางโปร่ง เรียบ และติดด้านบนเมื่อเลื่อนหน้า
- เพิ่มลิงก์ไปยัง “วิธีทำงาน” และ “Templates” ภายในหน้า โดยไม่เพิ่มเมนูหรือข้อมูลที่ยังไม่มีจริง
- คงปุ่มภาษา ธีม และเข้าสู่ระบบ/เข้าสู่ Dashboard ตามสถานะผู้ใช้

### 2. ส่วนเปิดหน้า
- ใช้ headline ไทยเดิมในลำดับสายตาที่ชัดขึ้น พร้อมเน้น “AI Agent” ด้วยสีแบรนด์อย่างมีวินัย
- เพิ่มป้ายข้อความสั้นจาก tagline ที่มีอยู่ และปรับ CTA หลัก/รองให้เด่นและเข้าใจง่าย
- สร้างภาพตัวอย่างผลิตภัณฑ์แบบ “Agent workspace” จาก UI จริงในระบบ เช่น เป้าหมาย ความรู้ Skills และสถานะพร้อมใช้งาน เพื่อสื่อว่าผู้ใช้กำลังสร้างอะไร ไม่ใช้ภาพตกแต่งลอย ๆ
- จัดความสูงให้เห็นส่วนถัดไปเล็กน้อย เพื่อชวนให้เลื่อนต่อ

### 3. ขั้นตอนการทำงาน
- เปลี่ยน 3 ขั้นตอนให้เป็นเส้นทางต่อเนื่องที่สแกนง่าย พร้อมเลขขั้นและไอคอนที่ชัด
- ปรับระยะห่าง ตัวอักษร และคำอธิบายให้ดูเป็นมืออาชีพทั้งภาษาไทยและอังกฤษ
- ใช้การเผยองค์ประกอบตามลำดับอย่างนุ่มนวล และรองรับผู้ใช้ที่ปิด animation

### 4. Templates
- ยกระดับการ์ด Template ให้เห็นหมวด ความสามารถ และทิศทางสีของแต่ละงานได้เร็วขึ้น
- ใช้ข้อมูล Template จริงที่มีอยู่เท่านั้น และคงการคลิกเพื่อเริ่มสร้าง Agent
- เพิ่มปุ่มนำไปดู Marketplace สำหรับผู้ใช้ที่เข้าสู่ระบบ หรือพาเข้าสู่ระบบก่อนตาม flow เดิม

### 5. ความสม่ำเสมอและการเข้าถึง
- ใช้สี ตัวอักษร ปุ่ม และค่าธีมจากระบบเดิม รองรับ light/dark mode
- รักษา Thai-first และทำข้อความใหม่ให้ครบทั้งไทย/อังกฤษ
- ตรวจ contrast, focus state, alt/aria label, heading structure และขนาดพื้นที่กดบนมือถือ
- ปรับหน้าให้ทำงานดีที่ desktop, tablet และ mobile โดยข้อความ/ปุ่มไม่ล้นหรือทับกัน

## แนวทางภาพที่เลือก
- **Modern professional minimalist**
- พื้นที่ว่างชัดเจน ตัวอักษรน้ำหนักสูง เส้นขอบบาง และเงานุ่ม
- สีม่วง/น้ำเงิน/ชมพูใช้เป็นจุดเน้น ไม่ครอบคลุมทั้งหน้า
- มุมโค้งควบคุมให้เรียบคม ไม่ใช้การ์ดซ้อนการ์ด และไม่ใช้ก้อนแสงเบลอเป็นของตกแต่ง
- Motion สั้น ลื่น และมีหน้าที่ช่วยลำดับสายตา

## รายละเอียดทางเทคนิค
- ปรับหน้า Landing และข้อความแปลที่เกี่ยวข้อง โดยไม่แตะระบบสร้าง Agent หรือข้อมูลหลังบ้าน
- ใช้โลโก้ ThoughtMind เดิมและส่วนประกอบปุ่มของระบบ
- ตรวจด้วย typecheck และเปิดทดสอบหน้า Landing จริงที่ viewport desktop/mobile รวมถึง light/dark mode และการนำทางของปุ่มสำคัญ
