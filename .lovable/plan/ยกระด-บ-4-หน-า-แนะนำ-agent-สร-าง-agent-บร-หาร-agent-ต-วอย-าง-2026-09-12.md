# ยกระดับ 4 หน้า: แนะนำ Agent, สร้าง Agent, บริหาร Agent, ตัวอย่างคำตอบจริง

ทั้งหมดใช้สไตล์เดียวกับหน้าแรกใหม่ (Modern Professional Minimalist): พื้นที่หายใจเยอะ ขอบมน เส้นบาง ตัวอักษรชัด สีตามธีมเดิม ไม่ใช้ข้อมูลปลอม

## 1. หน้าแนะนำ Agent (ยกระดับหน้า Marketplace เดิม)

- จัดกลุ่มตัวอย่างตาม "หมวดงาน" ที่คนเข้าใจทันที: สรุปงบ/การเงิน, แปลงข้อมูล, ตอบลูกค้า, ค้นคว้า-สรุปข่าว, เขียนเนื้อหา, ตอบจากเอกสาร
- แต่ละการ์ดเพิ่ม "Agent นี้ทำงานอย่างไร" แบบ 4 ขั้น: รับคำถาม → ค้นความรู้/เรียกเครื่องมือ → เรียบเรียงคำตอบ → อ้างอิงแหล่งที่มา พร้อมระบุเครื่องมือและโมเดลที่ใช้จริง
- เพิ่มตัวอย่างคำถามและตัวอย่างคำตอบจริงของแต่ละหมวด (ใช้ตัวอย่างชุดที่มีอยู่แล้วในระบบ) แสดงในหน้ารายละเอียดของแต่ละแบบ
- ปุ่ม "ใช้แบบนี้" ยังพาไปสร้าง Agent พร้อมค่าตั้งต้นเหมือนเดิม และยังนับยอดใช้งานจริงจากฐานข้อมูล
- ปรับหน้าตาให้เรียบขึ้น: หัวข้อชัด ตัวกรองหมวดเป็นแถบเดียว การ์ดสม่ำเสมอ ปุ่มไม่ซ่อนจนหาไม่เจอบนมือถือ

## 2. หน้าสร้าง Agent ให้เรียบง่ายขึ้น

- คงลำดับ 5 ขั้นตอนและตรรกะเดิมทั้งหมด ปรับเฉพาะการนำเสนอ
- แถบความคืบหน้าด้านบนแบบใหม่: เห็นชื่อขั้นตอน ขั้นที่ผ่านแล้ว และกดย้อนกลับได้
- หนึ่งขั้นตอน = หนึ่งการ์ดใหญ่ ใจความเดียว ลดกรอบซ้อนกรอบ จัดระยะห่างและขนาดตัวอักษรให้เท่ากันทุกขั้น
- คำอธิบายใต้ช่องกรอกสั้นลง ใช้ภาษาคนทั่วไป ส่วน "การตั้งค่าขั้นสูง" ยุบไว้และจัดกลุ่มให้หาง่าย
- แถบปุ่มถัดไป/ย้อนกลับติดด้านล่างบนมือถือ เพื่อไม่ต้องเลื่อนหา

## 3. หน้าบริหาร Agent (ยกระดับหน้า Dashboard เดิม)

- สลับมุมมองได้ระหว่างการ์ดกับตาราง ตารางแสดง: ชื่อ, สถานะ, โมเดล, จำนวนไฟล์ความรู้, ข้อความ 7 วันล่าสุด, โทเค็นที่ใช้, อัปเดตล่าสุด
- เลือกหลายรายการเพื่อเผยแพร่/พักการใช้งาน/ลบพร้อมกัน โดยการลบมีหน้าต่างยืนยัน
- แถวขยายดูสรุปเร็ว: เป้าหมาย, ทักษะ, เครื่องมือที่เปิดใช้, งบที่ตั้งไว้
- ปุ่มลัดไปแก้ไขการตั้งค่าขั้นสูงของ Agent นั้นโดยตรง
- ประวัติการใช้งานจริงจากฐานข้อมูล: กราฟ/ตัวเลขการใช้งานรายวัน และรายการสนทนาล่าสุดพร้อมลิงก์เปิดดู (ไม่มีข้อมูลสมมติ ถ้ายังไม่มีข้อมูลจะขึ้นสถานะว่าง)
- คงช่องค้นหา ตัวกรองสถานะ/โมเดล/ทักษะ และการเรียงลำดับเดิมไว้ครบ

## 4. หน้าตัวอย่างคำตอบจริง (หน้าใหม่ /showcase)

- แสดง Agent ที่คุณสร้างไว้จริง จัดกลุ่มตามหมวดงานเดียวกับข้อ 1
- แต่ละ Agent มีปุ่มคำถามตัวอย่าง กดแล้วคุยสดกับ Agent ตัวนั้นทันทีในหน้านี้ พร้อมแสดงแหล่งอ้างอิงและเวลาที่ใช้ตอบ
- ช่องพิมพ์คำถามเองได้ และมีปุ่ม "คุยกับ Agent" เพื่อเปิดห้องแชทเต็มรูปแบบ
- ถ้ายังไม่มี Agent จะชวนไปสร้างจากหน้าแนะนำแทน
- เพิ่มเมนูในแถบด้านข้างและลิงก์จากหน้าแรก

## รายละเอียดทางเทคนิค

- ไฟล์ที่แก้: `src/pages/Marketplace.tsx`, `src/pages/AgentBuilder.tsx` (+ `components/agent-builder/*` เฉพาะการจัดวาง), `src/pages/Dashboard.tsx` (+ `components/dashboard/*`), เพิ่ม `src/pages/Showcase.tsx`, route ใน `src/App.tsx`, เมนูใน `AppSidebar.tsx`, ข้อความใน `src/i18n/th.ts` และ `en.ts`
- ข้อมูลหมวดงาน + ขั้นตอนการทำงาน + คำถามตัวอย่าง เพิ่มเป็นฟิลด์ใหม่ใน `src/data/constants.ts` (ต่อยอด `MARKETPLACE_TEMPLATES`) และอ้างตัวอย่างจาก `src/data/userPromptExamples.ts`
- หน้า Showcase คุยสดผ่าน `streamChat` เดิม (ผ่านฟังก์ชัน `chat`) จึงได้ citations, การตรวจสอบคำตอบ, guardrails และงบประมาณเหมือนห้องแชทปกติ
- ประวัติการใช้งานอ่านจาก `agent_analytics_events`, `agent_usage_counters`, `conversations`, `chat_messages` โดยจำกัดตามผู้ใช้ที่ล็อกอิน
- ไม่แก้โครงสร้างฐานข้อมูล ไม่แก้ฟังก์ชันฝั่งเซิร์ฟเวอร์ และไม่เปลี่ยนตรรกะการบันทึก Agent เดิม
