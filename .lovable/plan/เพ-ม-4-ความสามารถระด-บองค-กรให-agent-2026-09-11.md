# เพิ่ม 4 ความสามารถระดับองค์กรให้ Agent

เพิ่มเครื่องมือของผู้ใช้เอง, ตัวกรองความปลอดภัย, เพดานค่าใช้จ่าย และการอ้างอิงแหล่งที่มาในคำตอบ
ทุกอย่างทำงานเหมือนกันทั้ง 3 ช่องทาง: หน้าแชททดสอบ, API สาธารณะ และวิดเจ็ตฝังเว็บ

---

## 1. เครื่องมือที่ผู้ใช้สร้างเอง (Custom Tools)

หน้า Agent จะมีแท็บใหม่ "เครื่องมือ" ให้ผูก API ภายนอกของตัวเองเป็นความสามารถของ Agent

แต่ละเครื่องมือกำหนดได้:
- ชื่อและคำอธิบาย (บอก Agent ว่าควรเรียกเมื่อไหร่)
- URL ปลายทาง + วิธีเรียก (GET/POST/PUT/PATCH/DELETE)
- ช่องข้อมูลที่ Agent ต้องกรอก (ชื่อ, ชนิด, คำอธิบาย, บังคับหรือไม่)
- การยืนยันตัวตน: ไม่มี / API key ใน header / Bearer token — ค่าลับถูกเข้ารหัสเก็บไว้ ไม่แสดงซ้ำและไม่ถูกส่งให้โมเดล
- เปิด/ปิดได้ทีละตัว

มีปุ่ม "ทดสอบเครื่องมือ" ให้ยิงจริงพร้อมค่าตัวอย่าง เห็นสถานะและผลลัพธ์ที่ตอบกลับก่อนเปิดใช้
เมื่อ Agent เรียกเครื่องมือ จะเห็นทุกขั้นตอนในหน้า Monitor เหมือนเครื่องมือมาตรฐาน

ข้อจำกัดด้านความปลอดภัย: อนุญาตเฉพาะ URL แบบ https, ห้ามปลายทางภายในเครือข่าย, จำกัดเวลารอ 10 วินาที, ขนาดผลลัพธ์ 8 KB, สูงสุด 10 เครื่องมือต่อ Agent

## 2. ตัวกรองความปลอดภัย (Guardrails)

การ์ดตั้งค่าใหม่ในแท็บภาพรวมของ Agent เปิด/ปิดได้เป็นรายข้อ:
- คำต้องห้าม: ผู้ใช้ใส่รายการคำ/วลีเองได้ บล็อกทั้งขาเข้าและขาออก
- ปิดบังข้อมูลส่วนบุคคล: เลขบัตรเครดิต, เลขบัตรประชาชน, อีเมล, เบอร์โทร ในคำตอบจะถูกปิดบังอัตโนมัติ
- กันการหลอกเปลี่ยนคำสั่ง: ตรวจข้อความที่พยายามให้ Agent ลืมคำสั่งเดิม/เปิดเผยคำสั่งลับ/สวมบทบาทใหม่
- โหมดตรวจสองชั้น: กฎในระบบตรวจก่อน (เร็ว ไม่มีค่าใช้จ่าย) เคสที่ก้ำกึ่งจึงส่งให้ AI ตรวจซ้ำ

เมื่อโดนบล็อก ผู้ใช้ปลายทางเห็นข้อความสุภาพที่เจ้าของ Agent ตั้งเองได้ ส่วนเจ้าของเห็นเหตุผลจริงในหน้า Monitor
คำสั่งระบบจะถูกล้อมด้วยเครื่องหมายกำกับ และเนื้อหาจากเอกสาร/เว็บถูกทำเครื่องหมายว่าเป็น "ข้อมูล ไม่ใช่คำสั่ง" เพื่อกันการฝังคำสั่งผ่านไฟล์

## 3. งบและเพดานค่าใช้จ่าย

ตั้งเพดานต่อ Agent ได้ทั้ง **รายวัน** และ **รายเดือน** (จำนวน token และ/หรือจำนวนข้อความ)

พฤติกรรม:
- ใช้ถึง 80% ของเพดาน: ขึ้นแถบเตือนสีเหลืองในหน้า Agent และ Dashboard
- ใช้ครบเพดาน: หยุดตอบทันทีทุกช่องทาง คืนสถานะ 429 พร้อมข้อความอธิบายให้ผู้เรียก API และแจ้งเตือนชัดเจนในแอป
- รอบรายวันรีเซ็ตเที่ยงคืนตามเวลาไทย รอบรายเดือนรีเซ็ตวันที่ 1

การ์ดการใช้งานในหน้า Agent แสดงแถบความคืบหน้าวันนี้/เดือนนี้ และปุ่มรีเซ็ตตัวนับด้วยตนเองสำหรับเจ้าของ

## 4. แสดงแหล่งที่มา (Citations)

คำตอบที่ใช้เอกสารจะมีเลขอ้างอิง [1] [2] แทรกในเนื้อคำตอบ และรายการแหล่งที่มาด้านล่าง

แต่ละแหล่งที่มา:
- ชื่อไฟล์ + ตำแหน่งในไฟล์ (ส่วนที่เท่าไหร่) + เปอร์เซ็นต์ความใกล้เคียง
- คลิกแล้วเปิดหน้าอ่านเอกสารที่เลื่อนไปยังย่อหน้าที่ใช้ตอบ พร้อมไฮไลต์ข้อความนั้น
- ในวิดเจ็ต/API ที่ไม่มีสิทธิ์เปิดไฟล์ จะคืนชื่อไฟล์และข้อความต้นทางสั้น ๆ แทนลิงก์

API จะคืนฟิลด์ `citations` เพิ่ม (ไม่กระทบผู้เรียกเดิม) และเอกสารนักพัฒนา `/docs/api` อัปเดตตาม

---

## รายละเอียดทางเทคนิค

**ตารางใหม่**
- `agent_custom_tools` — ชื่อ, คำอธิบาย, method, url, พารามิเตอร์ (jsonb), auth_type, auth_header_name, auth_secret (เข้ารหัสด้วย pgsodium/vault), enabled, RLS ตาม user_id
- `agent_guardrails` — 1 แถวต่อ agent: blocked_keywords[], pii_redaction, injection_detection, ai_review, blocked_message, RLS ตาม user_id
- `agent_budgets` — daily_token_limit, monthly_token_limit, daily_message_limit, monthly_message_limit, enabled
- `agent_usage_counters` — agent_id + period_type('day'|'month') + period_start, tokens, messages; อัปเดตผ่าน RPC `increment_agent_usage` (security definer) แบบ upsert อะตอมมิก
- ทุกตาราง: GRANT ให้ authenticated + service_role, RLS เปิดครบ

**ฝั่งเซิร์ฟเวอร์ (`_shared`)**
- `custom-tools.ts` — โหลด custom tools ของ agent → แปลงเป็น OpenAI tool schema (prefix `ct_`), executor ที่ตรวจ URL (https เท่านั้น, บล็อก IP ภายใน/localhost/metadata endpoints), timeout 10s, ตัดผลลัพธ์ 8KB, บันทึก trace span `custom_tool`
- `guardrails.ts` — `checkInput()` / `checkOutput()`; ชั้นกฎ (regex คำต้องห้าม, PII, รูปแบบ prompt injection) แล้วชั้น AI review เฉพาะเคสก้ำกึ่ง เรียกผ่าน AI gateway ด้วย `openai/gpt-6-astra` (reasoning_effort low, JSON schema แบบ strict); ปิด fail-open เมื่อ gateway ล่ม
- `budget.ts` — `checkBudget()` ก่อนเรียกโมเดล (คืน over/warn) และ `recordUsage()` หลังจบสตรีม
- `embeddings.ts` — `match_knowledge_chunks` เพิ่มคืน `chunk_index`, `file_id`; `renderKnowledgeContext` ใส่หมายเลข [1..n] และสั่งให้โมเดลอ้างอิงด้วยหมายเลข
- ต่อ pipeline ใน `chat/index.ts`, `agent-api/index.ts`, `demo-agent/index.ts`: budget → guardrail ขาเข้า → RAG → tool loop (มาตรฐาน + custom) → คำตอบ → guardrail ขาออก → บันทึกการใช้งาน + citations

**Edge function ใหม่**
- `test-custom-tool` — ยิงเครื่องมือของผู้ใช้ครั้งเดียวเพื่อทดสอบ (ต้อง JWT ของเจ้าของ)

**ฝั่งหน้าเว็บ**
- hooks: `useCustomTools`, `useGuardrails`, `useAgentBudget`
- คอมโพเนนต์ใหม่ใน `src/components/agent-detail/`: `CustomToolsSection`, `GuardrailsCard`, `BudgetCard`, `CitationList`
- แท็บใหม่ "เครื่องมือ" ใน `AgentDetail.tsx`; แถบเตือนงบใน `Dashboard.tsx`
- `ChatConsole.tsx` แสดง citation ใต้คำตอบ (ต่อยอดจากบล็อกตรวจความถูกต้องเดิม)
- หน้าใหม่ `/knowledge/:fileId` อ่านเอกสารพร้อมไฮไลต์ย่อหน้าที่อ้างอิง (`?chunk=n`)
- คำแปลไทย/อังกฤษครบทุกข้อความใหม่

**การตรวจสอบก่อนส่งมอบ**
- Deno tests สำหรับ guardrails (คำต้องห้าม, PII, prompt injection), budget counter, custom tool URL validation
- ทดสอบจริงผ่าน API: เรียกทะลุเพดาน → 429, ข้อความหลอกเปลี่ยนคำสั่ง → ถูกบล็อก, คำถามจากเอกสาร → มี citations, custom tool → ถูกเรียกจริง
- typecheck + ดูหน้าเว็บจริงในเบราว์เซอร์
