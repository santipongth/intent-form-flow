# คู่มือการใช้งานฉบับมีภาพหน้าจอ (เวอร์ชัน 2)

เพิ่มภาพหน้าจอจริงของระบบเข้าไปในคู่มือภาษาไทย พร้อมคำอธิบายขั้นตอนแบบทีละขั้น เพื่อให้ผู้ใช้เห็นภาพและทำตามได้ทันที

## สิ่งที่จะได้

- ไฟล์ใหม่ `ThoughtMind-User-Manual-TH-v2.docx` และ `ThoughtMind-User-Manual-TH-v2.pdf` (ไฟล์เดิมยังอยู่ครบ)
- ทุกบทที่เป็นงานใช้งานจริง จะมีภาพหน้าจอประกอบ พร้อมคำบรรยายใต้ภาพ เช่น "ภาพที่ 3.1 หน้าสร้าง Agent ขั้นตอนที่ 1"
- ขั้นตอนแบบเรียงลำดับ 1-2-3 ใต้แต่ละภาพ บอกว่าต้องกดปุ่มไหน กรอกอะไร ผลลัพธ์คืออะไร

## ภาพหน้าจอที่จะถ่าย

ถ่ายจากระบบจริงที่รันอยู่ (ล็อกอินด้วยบัญชีทดสอบ) ไม่ใช้ภาพปลอมหรือภาพวาดจำลอง:

1. หน้าแรก (Landing) และหน้าเข้าสู่ระบบ
2. แดชบอร์ด: มุมมองการ์ด และมุมมองตาราง
3. สร้าง Agent ใหม่: ทั้ง 5 ขั้นตอน รวมส่วนตั้งค่าขั้นสูง
4. หน้าจัดการ Agent: ภาพรวม, คลังความรู้ (อัปโหลดไฟล์ + เพิ่ม URL), เครื่องมือและความจำ, การเผยแพร่ (API/Widget)
5. หน้าทดลองคุย (Chat Console) พร้อมคำตอบที่มีการอ้างอิงแหล่งที่มา
6. คลัง Agent สำเร็จรูป (Marketplace) และหน้าตัวอย่าง (Showcase)
7. Monitor: ไทม์ไลน์ขั้นตอนการคิดและเวลาที่ใช้
8. Analytics และหน้าเปรียบเทียบ Agent
9. Skills, โปรไฟล์, การตั้งค่า

หน้าไหนที่ยังไม่มีข้อมูลจริงพอจะถ่าย จะระบุไว้ในคู่มือว่าเป็นหน้าที่จะมีข้อมูลเมื่อเริ่มใช้งาน แทนการสร้างข้อมูลปลอม

## โครงคู่มือ

คงโครง 17 บทเดิมไว้ แล้วเสริม:
- กล่อง "ทำตามนี้" (ขั้นตอนสั้น) ใต้ภาพแต่ละใบ
- บทใหม่ "ตัวอย่างงานจริงทีละขั้น" รวม 3 สถานการณ์: สร้าง Agent ตอบลูกค้าจากไฟล์เอกสาร, เชื่อม Agent เข้าเว็บไซต์ด้วย Widget, ตรวจสอบคุณภาพคำตอบด้วย Monitor
- สารบัญภาพ

## รายละเอียดทางเทคนิค

- ใช้ Playwright ถ่ายภาพที่ความกว้าง 1280 (เดสก์ท็อป) โหมดสว่าง ภาษาไทย เก็บไว้ที่ `/tmp/manual-shots/`
- สคริปต์สร้างเอกสารเขียนใหม่ใน `/tmp` ด้วย python-docx (ฝังภาพ ปรับความกว้างพอดีหน้า) แล้วแปลงเป็น PDF
- ตรวจสอบคุณภาพ: แปลง PDF ทุกหน้าเป็นรูปแล้วไล่ดูทีละหน้า หาข้อความล้น ภาพขาด ฟอนต์ไทยเพี้ยน แล้วแก้จนสะอาด
- ไม่แก้ไขโค้ดของแอป งานนี้เป็นการสร้างเอกสารอย่างเดียว
