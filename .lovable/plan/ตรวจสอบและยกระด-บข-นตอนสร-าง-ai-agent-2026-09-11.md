# ตรวจสอบและยกระดับขั้นตอนสร้าง AI Agent

## สิ่งที่ตรวจพบจริงในระบบตอนนี้

- **Max Tokens**: หน้าสร้างและหน้าแก้ไขให้กรอกค่าได้ และบันทึกลงฐานข้อมูลจริง แต่ตอนคุยกับ Agent ระบบ **ไม่ได้นำค่านี้ไปใช้เลย** (ตรวจแล้วในโค้ดฝั่งแชทและ API) — ผู้ใช้ตั้งค่าแล้วไม่มีผล
- **Temperature (ความสร้างสรรค์)**: ใช้ได้จริงกับบางรุ่นเท่านั้น รุ่นตระกูล GPT-5 ระบบจะตัดค่านี้ทิ้งอัตโนมัติ แต่หน้าจอยังโชว์แถบเลื่อนโดยไม่บอกผู้ใช้
- **User Prompt / Skills / System Prompt**: ถูกนำไปใช้จริงในการตอบแล้ว
- ขั้นตอนปัจจุบัน 5 ขั้น (ประเภท → ชื่อ/โมเดล → ความรู้ → เครื่องมือ → ตรวจสอบ) ถือว่าตรงหลักสากล แต่ยังขาดจุดสำคัญ 2 อย่าง: **ไม่มีการทดลองคุยก่อนสร้าง** และ **ไม่มีการบังคับกรอกข้อมูลจำเป็น** (กด "ถัดไป" ได้แม้ยังไม่ใส่ชื่อ)

## ข้อเสนอ: ปรับ "การตั้งค่าขั้นสูง" ให้ตรงกับความจริงและครบตามมาตรฐาน

**คงไว้และทำให้ทำงานจริง**

- System Prompt (บทบาทของ Agent)
- User Prompt (แม่แบบคำถาม — ไม่บังคับ)
- Skills
- ความสร้างสรรค์ (Temperature) — ซ่อน/แสดงข้อความกำกับอัตโนมัติเมื่อรุ่นที่เลือกไม่รองรับ
- ความยาวคำตอบสูงสุด (Max Tokens) — ต่อสายให้ส่งไปใช้จริงตอนตอบ พร้อมเปลี่ยนช่องกรอกตัวเลขดิบเป็นตัวเลือกอ่านง่าย (สั้น / ปานกลาง / ยาว / กำหนดเอง)

**เพิ่มใหม่ (มาตรฐานของแพลตฟอร์ม Agent ระดับมืออาชีพ)**

- ข้อความทักทายเริ่มต้น และ คำถามตัวอย่าง 3 ข้อ (ใช้ทั้งใน Chat Console และ Widget)
- ข้อความสำรองเมื่อไม่พบคำตอบในคลังความรู้ + สวิตช์ "ตอบเฉพาะจากคลังความรู้เท่านั้น"
- จำนวนรอบการใช้เครื่องมือสูงสุดต่อคำถาม
- ลิงก์ไปตั้งค่าความปลอดภัยและงบประมาณที่มีอยู่แล้วในหน้า Agent

**ไม่เพิ่ม**: ค่าเชิงเทคนิคลึกอย่าง top_p / penalty ต่าง ๆ เพราะซ้ำซ้อนกับ Temperature และทำให้ผู้ใช้ทั่วไปสับสน

## ปรับ UX/UI ของขั้นตอนสร้าง

1. **ตรวจสอบก่อนไปขั้นถัดไป**: ต้องมีชื่อและเป้าหมาย Agent ก่อน มิฉะนั้นปุ่ม "ถัดไป" ไม่ทำงานพร้อมข้อความอธิบาย
2. **ขั้นตอนที่ 5 เพิ่มกล่องทดลองคุย**: ทดสอบ Agent ได้ทันทีก่อนกดสร้าง
3. **แยกการตั้งค่าขั้นสูงเป็นหมวดพับได้** 3 หมวด: บุคลิกและคำสั่ง / รูปแบบคำตอบ / ขอบเขตและความปลอดภัย แทนรายการยาวก้อนเดียว
4. **ทุกช่องมีคำอธิบายสั้นและตัวอย่าง** ผ่านไอคอนเครื่องหมายคำถาม ไม่ใช้ศัพท์เทคนิคลอย ๆ
5. **สรุปก่อนสร้างอ่านง่ายขึ้น**: แสดงเฉพาะสิ่งที่ตั้งไว้จริง พร้อมปุ่ม "แก้ไข" กระโดดกลับไปขั้นที่เกี่ยวข้อง
6. **บันทึกร่างอัตโนมัติ** ในเครื่อง กันข้อมูลหายเมื่อปิดหน้าไปกลางคัน
7. **แจ้งเตือนความพร้อม**: ถ้ายังไม่มีไฟล์/URL ในคลังความรู้ ให้เตือนว่า Agent จะตอบจากความรู้ทั่วไปเท่านั้น
8. ช่วยทำ user prompt ให้ผู้ใช้เข้าใจ และใช้งานง่ายกว่านี้

## รายละเอียดทางเทคนิค

- `supabase/functions/chat/index.ts` และ `supabase/functions/agent-api/index.ts`: อ่าน `agents.max_tokens` แล้วส่งเป็น `max_completion_tokens` ไป gateway พร้อม clamp ช่วงที่ปลอดภัย
- `supabase/functions/_shared/models.ts`: ใช้ `supportsCustomTemperature()` ที่มีอยู่แล้วมา export ให้ฝั่งหน้าเว็บใช้ตัดสินใจซ่อนแถบเลื่อน (คัดลอกรายการรุ่นเป็น constant ฝั่ง client)
- ฟิลด์ใหม่ (greeting, starters, fallback, strict-knowledge, tool-loop cap) เก็บใน `agents.tools` JSON เหมือน `_userPrompt` / `_skills` เพื่อไม่ต้องแก้โครงสร้างตาราง แล้วอ่านผ่าน helper ใน `src/lib/agentTools.ts`
- แก้หน้า `src/pages/AgentBuilder.tsx` (ขั้นตอน/validation/preview chat) และ `src/pages/AgentDetail.tsx` ให้แก้ไขฟิลด์เดียวกันได้ พร้อมข้อความ i18n ไทย/อังกฤษ
